# Amazon Web Clone

## 📌 Overview

This project is a simple frontend clone of the Amazon homepage built using HTML and CSS. It was created as a beginner-level project to practice core web development concepts such as page structure, layout design, and styling.

The goal of this project is to understand how real-world websites are structured and styled using basic frontend technologies.

## 🛠️ Tech Stack

* HTML5
* CSS3

## ✨ Features

* Static Amazon homepage UI clone
* Clean and simple layout structure
* Styled using pure CSS
* Beginner-friendly project

## 📂 Project Structure

* `amazon.html` – Main HTML file
* `amazon.css` – Stylesheet for the webpage
* `README.md` – Project documentation
